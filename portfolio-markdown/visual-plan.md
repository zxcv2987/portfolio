# Visual Evidence Plan

이미지가 없어도 포트폴리오 사이트의 첫 버전을 만들 수 있습니다. 다만 프로젝트 상세 페이지가 긴 글로만 구성되면 문제와 해결 과정이 실제로 어떻게 연결되는지 파악하는 데 시간이 더 걸립니다.

모든 프로젝트에 많은 스크린샷이 필요한 것은 아닙니다. 대표 사례마다 설명력이 높은 자료 1~2개만 추가해도 충분합니다.

## 우선순위

### 1. 관리자 시스템 리뉴얼

가장 가치가 높은 시각 자료:

- 개선 전과 후의 책임 구조를 비교한 간단한 구조도
- 빌드 시간 5~10분과 약 30초를 비교한 수치 그래픽
- 공개 가능한 공통 테이블·필터·폼 화면 1장

실제 회사 화면을 공개하기 어렵다면 코드나 화면 캡처 대신 추상화한 구조도를 직접 제작합니다.

### 2. 기기 판별 로직 개선

가장 가치가 높은 시각 자료:

- 기존 UA 단일 판별과 개선된 복수 신호 판별의 흐름도
- Sentry 화면 자체보다 익명화한 환경 정보 요약
- 데스크톱, 태블릿, 터치 노트북의 조건 비교표

사용자 정보가 포함된 실제 Sentry 화면은 가급적 사용하지 않습니다.

### 3. 동글

가장 가치가 높은 시각 자료:

- 사용자 앱과 관리자 앱 사이의 캐시 무효화 흐름도
- 릴리스, 심볼릭 링크, PM2, 헬스체크, 롤백 흐름도
- 사용자 홈과 관리자 화면을 함께 보여주는 서비스 화면

동글은 코드 구조와 운영 흐름이 강점이므로 단순 화면 캡처보다 흐름도가 더 중요합니다.

### 4. 전남 청년 문화복지카드

가장 가치가 높은 시각 자료:

- 지도에서 가맹점과 은행별 정보를 확인하는 실제 화면
- 웹과 Flutter 앱 사이의 위치 정보 전달 구조
- 사용자 수와 앱 다운로드 수를 보여주는 수치 영역

### 5. 코펫

- 지도 위 산책 경로 화면
- 커뮤니티 화면
- 위치 추적 상태 흐름

현재 Notion 내보내기에 있는 화면을 사용할 수 있지만, 프로젝트 우선순위가 낮으므로 대표 프로젝트 자료를 먼저 정리합니다.

### 6. 빈차

별도 이미지 없이도 괜찮습니다. 기타 프로젝트 카드에서 간단히 소개하고, 상세 페이지가 필요할 때만 실제 화면 1장을 추가합니다.

## 이미지가 전혀 없을 때의 대안

실제 스크린샷이 없더라도 다음 요소를 코드로 표현할 수 있습니다.

- 숫자 비교
- 단계별 문제 해결 흐름
- 선택지 비교표
- 시스템 구성 요소와 화살표
- 타임라인
- 기술 선택 기준

이런 요소는 장식용 이미지보다 정보 전달력이 높고, 회사 내부 화면을 노출하지 않아도 된다는 장점이 있습니다.

## 최소 권장 구성

사이트 첫 공개 시점에는 아래 네 가지면 충분합니다.

1. 관리자 시스템 구조 개선 전후 다이어그램
2. 빌드 시간 비교
3. 동글 캐시 무효화 흐름도
4. 동글 배포 롤백 흐름도

나머지 이미지는 사이트를 먼저 공개한 뒤 순차적으로 추가해도 됩니다.
