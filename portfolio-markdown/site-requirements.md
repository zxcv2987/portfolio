# Site Requirements

## 기술 방향

- Next.js App Router
- TypeScript
- Tailwind CSS
- Markdown 또는 MDX 기반 콘텐츠 관리
- 정적 생성 우선
- Vercel 배포
- 별도 데이터베이스와 관리자 페이지는 사용하지 않음

## 콘텐츠 처리

- 각 Markdown 파일의 frontmatter를 프로젝트 카드와 메타데이터에 사용
- 본문은 상세 페이지에서 렌더링
- `featured`와 `order`로 홈 노출 여부와 순서를 결정
- `TODO`가 포함된 항목은 공개 화면에서 숨기거나 확인 완료 후 노출
- 제공되지 않은 정보는 자동 생성하지 않음
- 수치, 기간, 팀 구성, 기여도는 원문 그대로 사용하고 임의로 보정하지 않음

## 필수 페이지

- `/` 홈
- `/experience`
- `/case-studies/[slug]`
- `/projects/[slug]`

## 필수 기능

- 반응형 레이아웃
- 프로젝트 목록과 상세 페이지
- 이전·다음 프로젝트 이동
- 이메일과 GitHub 링크
- PDF 이력서 열기 또는 다운로드
- Open Graph 메타데이터
- sitemap과 robots 설정
- 키보드 탐색
- 적절한 제목 구조와 시맨틱 HTML
- 이미지 추가 시 Next.js Image 최적화
- 코드 블록과 긴 본문 가독성
- 모바일 목차 또는 섹션 이동

## 성능 원칙

- 불필요한 클라이언트 컴포넌트 사용 금지
- 애니메이션은 핵심 정보 탐색을 방해하지 않는 수준으로 제한
- 콘텐츠 페이지는 서버 컴포넌트와 정적 렌더링을 우선
- 웹폰트와 대형 이미지로 초기 렌더링을 지연시키지 않음

## 접근성 원칙

- 텍스트와 배경의 충분한 명도 대비
- 키보드 포커스 표시
- 링크 목적을 설명하는 텍스트
- 장식 이미지와 정보 이미지의 대체 텍스트 구분
- 모션 감소 설정 존중
- 모바일에서도 16px 이상의 본문 글자 크기 유지

## 콘텐츠 안전

- 회사 내부 사용자 정보, URL, 토큰, 운영 데이터 노출 금지
- Sentry 화면을 공개할 경우 사용자 식별 정보 제거
- 회사 화면을 공개하기 전에 허용 범위 확인
- 연락처는 이메일과 GitHub를 기본으로 사용하고 전화번호는 공개 사이트에서 제외
