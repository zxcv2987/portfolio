# 포트폴리오 콘텐츠 원본

이 폴더는 포트폴리오 사이트를 AI 또는 직접 개발 방식으로 제작할 때 사용하는 콘텐츠 원본입니다.

## 콘텐츠 원칙

- 이력서는 핵심 문제와 결과를 압축해 보여줍니다.
- 포트폴리오는 이력서의 내용을 문제, 판단, 구현, 결과 순서로 확장합니다.
- 제공되지 않은 성과, 수치, 역할, 팀 구성은 임의로 만들지 않습니다.
- 확인이 필요한 항목은 `TODO`로 유지합니다.
- 사이트 디자인이 바뀌어도 콘텐츠 파일은 재사용할 수 있도록 프로젝트별로 분리합니다.

## 추천 노출 순서

1. 주식회사 팀마파 경력
2. 관리자 시스템 리뉴얼
3. 데스크톱 전용 서비스의 기기 판별 개선
4. 동글
5. 전남 청년 문화복지카드 사용처 검색
6. 코펫
7. 빈차

## 작성 상태

본문은 현재 Notion 포트폴리오 내보내기와 최신 점핏 이력서에 근거해 정리했습니다. 아래 항목은 공개 전에 확인이 필요합니다.

- 동글 팀 구성과 본인 기여 범위
- 전남 청년 문화복지카드 프로젝트 기간
- 사용자 5,400명 지표의 정확한 측정 기준
- 전남 청년 문화복지카드의 정확한 수상 등급
- 코펫 프로젝트 기간
- 빈차의 최종 인증 쿠키 설정 방식
- 공개 가능한 회사 화면, 로그, 구조도 범위
