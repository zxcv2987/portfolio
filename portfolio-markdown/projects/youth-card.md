# 전남 청년 문화복지카드 사용처 검색

## 한눈에 보기

전라남도의 청년 정책인 문화복지카드의 사용처를 지도와 검색으로 제공하는 서비스입니다.

기존에는 이용 가능한 가맹점을 확인하기 위해 지자체 홈페이지에서 엑셀 파일을 내려받아야 했습니다. 이를 지도 기반 서비스로 전환하고, 모바일 접근성과 위치 기능을 보완하기 위해 Flutter WebView 앱으로 확장했습니다.

## 사용 대상

전남 도내에서 2년 이상 거주한 19~28세 청년을 대상으로 한 서비스입니다.

> 정책 대상 연령과 거주 조건은 포트폴리오 작성 당시 기준입니다. 공개 전 최신 정책이 아니라 프로젝트 당시 정책임을 명시합니다.

## 문제 상황

- ‘문화 및 공연 관람에 사용 가능’처럼 사용처 안내가 추상적이었음
- 실제 가맹점을 찾으려면 지자체 홈페이지에서 엑셀 파일을 내려받아야 했음
- 현재 위치 주변에서 사용할 수 있는 장소를 빠르게 확인하기 어려웠음
- 은행에 따라 사용 가능 여부가 달라 세부 정보 확인이 필요했음

## 제공한 기능

- 문화복지카드 가맹점을 지도에 표시
- 검색과 지역 필터 제공
- 지도 오버레이에서 가맹점 세부 정보 제공
- 은행별 사용 가능 여부 제공
- 네이티브 위치 정보를 이용한 현재 위치 기반 탐색

## 담당 범위

### Web

- React와 TypeScript 기반 UI 구현
- 지도 화면과 지역별 탐색 흐름 구현

### Flutter App

- 기존 웹 서비스를 Flutter WebView 앱으로 확장
- 웹과 네이티브 앱 사이의 위치 정보 전달
- Android 권한 처리
- 앱 빌드와 Google Play Console 출시 관리

사용자가 실제로 불편을 느끼는 탐색 과정을 줄여야 서비스가 사용된다는 점을 체감했습니다.
