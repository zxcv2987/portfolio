# 강태양 | Frontend Engineer

실제 사용자 환경에서 발생한 문제를 데이터로 추적하고, 복잡한 업무 흐름을 이해하기 쉬운 제품 경험으로 구체화합니다. 프론트엔드를 중심으로 일하지만 필요한 경우 API, 권한, 실시간 처리와 데이터 이전까지 제품의 완성에 필요한 경계를 함께 다룹니다.

사내 이슈 관리 시스템은 기존 협업 도구의 문제에서 요구사항과 제품 정책을 정리해 애플리케이션 개발을 1인으로 담당했고, 관리자 시스템은 실제 요구를 다시 검토해 Vite 기반으로 재구성하며 빌드 시간을 약 10분에서 약 30초로 단축했습니다. 갤럭시 태블릿이 데스크톱으로 오인되던 문제는 Sentry 환경 데이터로 원인을 확인하고 여러 브라우저 신호를 조합해 해결했습니다.

기술 도입 자체보다 현재 서비스의 제약과 업무 흐름을 먼저 파악하고, 선택의 근거와 변경 이후의 영향을 설명할 수 있는 개발을 지향합니다.
