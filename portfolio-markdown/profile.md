# 강태양 | Frontend Engineer

운영 중인 서비스의 업무 흐름과 데이터 구조를 이해하고, 복잡하게 결합된 프론트엔드 구조를 개선해 왔습니다.

관리자 시스템의 빌드 시간을 5~10분에서 약 30초로 단축했으며, 실제 사용자 환경에서 발생한 기기 판별 문제를 Sentry 데이터로 추적하고 여러 브라우저 신호를 조합해 해결했습니다.

기술 도입 자체보다 현재 서비스의 제약과 운영 흐름을 먼저 파악하고, 선택의 근거와 변경 이후의 영향을 설명할 수 있는 개발을 지향합니다.

## 핵심 경험

- Next.js 기반 관리자 시스템을 Vite, React 19, TanStack Router 구조로 전환
- 빌드 시간을 5~10분에서 약 30초로 단축해 개발 피드백 속도 약 90~95% 개선
- Sentry를 활용해 실제 사용자 브라우저·디바이스 환경 분석
- 독립 배포된 사용자·관리자 앱 사이의 선택적 캐시 무효화 구조 구현
- 헬스체크 실패 시 이전 정상 릴리스로 복구하는 배포 구조 구성
- 한글 IME 입력과 URL 상태를 고려한 검색 경험 개선
