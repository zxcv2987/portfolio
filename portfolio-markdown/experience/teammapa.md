# 주식회사 팀마파

프론트엔드 개발자로 근무하며 관리자 시스템 리뉴얼과 운영 중인 사용자 서비스의 문제 개선을 담당했습니다.

## 주요 업무

- 기존 Next.js 기반 관리자 시스템의 구조와 빌드 병목 분석
- Vite, React 19, TanStack Router 기반 관리자 시스템 재구성
- 인증, 권한, 라우팅, UI, 서버 상태, API 요청 책임 분리
- 반복되는 테이블, 필터, 폼 패턴을 위한 공통 구조 설계
- 운영 업무 흐름과 주요 도메인 규칙 문서화
- Sentry를 이용한 실제 사용자 오류 및 실행 환경 분석
- 데스크톱 전용 서비스의 브라우저·디바이스 판별 로직 개선

## 대표 성과

- 관리자 시스템 빌드 시간 5~10분에서 약 30초로 단축
- 개발 피드백 속도 약 90~95% 개선
- 기능 변경 시 수정 계층과 영향 범위를 더 명확하게 구분
- 단일 User-Agent에 의존하던 기기 판별 로직의 예외 대응 범위 확대
